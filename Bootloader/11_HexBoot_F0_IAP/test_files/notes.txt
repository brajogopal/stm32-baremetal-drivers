Project : 10_HexBoot_F0_FirmwareValidation

Objective:
Store firmware metadata after successful CRC verification
and verify metadata can be read back correctly from Flash.

Metadata Structure:
- APP_MAGIC       : 0xDEADBEEF
- Firmware Length : uint32_t
- Firmware CRC    : uint16_t

Flash Layout:
0x08004000 : Metadata
0x08004020 : Application

Test Payload:
11 22 33 44 55 66 77 88

Expected Results:
Firmware Length : 8 Bytes
Firmware CRC    : 0x5DB5

Verification Steps:
1. Receive firmware through UART.
2. Verify CRC.
3. Store firmware in Flash.
4. Create metadata.
5. Store metadata in Flash.
6. Read metadata back from Flash.
7. Print metadata through UART.
8. Verify stored values match expected values.

Observed Results:
magic_number    : 0xDEADBEEF
firmware_length : 0x00000008
firmware_crc    : 0x5DB5

Status:
PASS

Limitations:
- Metadata validation demonstrated through Flash readback.
- Boot-time application validation and jump logic will be integrated in Project 11.
- Single application slot architecture.
