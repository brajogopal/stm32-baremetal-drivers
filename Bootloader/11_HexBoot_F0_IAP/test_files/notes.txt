Project : 11_HexBoot_F0_IAP

Description:
This project demonstrates a complete In-Application Programming (IAP)
bootloader on STM32F030C8T6 using register-level programming.

Features Implemented:
- UART firmware reception
- Custom firmware packet format
- CRC16 firmware verification
- Flash programming
- Firmware metadata storage
- Application validation using metadata
- Multi-page flash erase support
- Automatic jump to valid application
- UART timeout handling

Firmware Packet Format:
------------------------------------------------
| Header (1 Byte) | Length (2 Bytes) |
------------------------------------------------
| Firmware Payload (N Bytes)          |
------------------------------------------------
| CRC16 (2 Bytes)                     |
------------------------------------------------

Memory Map:
Bootloader          : 0x08000000
Metadata            : 0x08004000
Application A       : 0x08004020

Important Learning:
- Flash pages must be erased before programming.
- Firmware larger than one flash page requires
  multiple page erase operations.
- Application validation is performed using metadata.
- CRC verifies firmware integrity before programming.

Known Limitation:
Entire firmware is stored in RAM before flash
programming.
